## Название проекта

**Реализация атак на LLM-модели и библиотеки, используемые для реализации моделей машинного обучения или нейронных сетей на примере TensorFlow**

Проект содержит практическую реализацию прототипа защитной модели для классификации пользовательских запросов к LLM-модели. Модель определяет тип запроса и принимает решение, можно ли передавать его дальше в LLM-систему.

Поддерживаемые классы:

- `benign` — безопасный пользовательский запрос;
- `prompt_injection` — попытка prompt injection;
- `jailbreak` — попытка jailbreaking;
- `system_prompt_extraction` — попытка извлечения системного промпта;
- `tool_abuse` — попытка несанкционированного использования инструментов.

Также в рамках проекта рассматривается уязвимость TensorFlow/Keras, связанная с небезопасной десериализацией моделей и использованием `Lambda`-слоя.

## Описание работы программы

На первом этапе текстовый запрос пользователя преобразуется в числовой embedding-вектор с помощью предобученной модели:

```text
sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
```

Полученные embedding-векторы образуют матрицу признаков. Далее матрица передается в классификатор логистической регрессии из библиотеки `scikit-learn`. Классификатор определяет наиболее вероятный класс запроса и принимает решение:

```text
allow — запрос можно передать в LLM;
block — запрос должен быть заблокирован.
```
